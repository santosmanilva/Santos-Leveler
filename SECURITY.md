# Seguridad / Security policy

## Español

### Versiones con soporte

Se corrigen los problemas de seguridad en la **última versión publicada** (consulta [Releases](https://github.com/santosmanilva/Santos-Leveler/releases)).

### Cómo informar de una vulnerabilidad

No publiques los detalles en un Issue abierto.

- Si en la pestaña **Security** del repositorio aparece **Report a vulnerability**, úsalo: el informe es privado.
- Si no aparece, abre un [Issue](https://github.com/santosmanilva/Santos-Leveler/issues) que diga solo que quieres comunicar un problema de seguridad, **sin detalles técnicos**, y se te indicará cómo continuar de forma privada.

## English

### Supported versions

Security issues are fixed in the **latest published release** (see [Releases](https://github.com/santosmanilva/Santos-Leveler/releases)).

### Reporting a vulnerability

Please do not post the details in a public Issue.

- If the **Security** tab of the repository shows **Report a vulnerability**, use it: the report is private.
- If it does not, open an [Issue](https://github.com/santosmanilva/Santos-Leveler/issues) saying only that you want to report a security problem, **without technical details**, and you will be told how to continue privately.
