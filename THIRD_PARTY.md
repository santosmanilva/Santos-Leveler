# Third-party build dependency

## JUCE

This source project is configured to fetch JUCE 8.0.12 from the official `juce-framework/JUCE` repository during the CMake configure step.

JUCE is not bundled in this archive. Review and comply with the JUCE licence applicable to your use/distribution model before distributing binaries or source that incorporates JUCE.

## VST3

The VST3 wrapper/SDK used by the selected JUCE release is a build dependency. Review Steinberg's current VST3 developer portal and licensing information before public distribution.
