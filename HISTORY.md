# Historia del proyecto / Project history

## Español

Santos Leveler comenzó como una serie de prototipos experimentales creados en **MNodes**, el entorno modular de audio desarrollado por **Mario Nieto**.

MNodes permite construir procesadores de audio mediante una interfaz visual basada en nodos. Durante las primeras etapas del proyecto se utilizó para explorar y validar la idea de un nivelador automático de voz, su lógica de detección y distintos comportamientos de control dinámico antes de desarrollar la implementación VST3 nativa actual.

La versión actual de Santos Leveler no depende de MNodes en tiempo de ejecución y ha sido reimplementada como plugin VST3 nativo en C++/JUCE.

## English

Santos Leveler started as a series of experimental prototypes created in **MNodes**, the modular audio environment developed by **Mario Nieto**.

MNodes provides a visual node-based environment for building audio processors. During the early stages of the project it was used to explore and validate the concept of an automatic voice leveler, its detection logic and different dynamic-control behaviours before the current native VST3 implementation was developed.

The current Santos Leveler does not depend on MNodes at runtime and has been reimplemented as a native C++/JUCE VST3 plugin.
